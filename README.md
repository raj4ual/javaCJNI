# javaCJNI

Step 1: Write the Java Program (App.java)

Create the Java class that will load the compiled native library and declare the native function.
java
public class App {
    // Load the native library. The OS will look for libmycalculator.so (Linux/macOS) or mycalculator.dll (Windows)
    static {
        System.loadLibrary("mycalculator"); 
    }

    // Declare a native method that accepts two integers and returns an integer
    public native int addNumbers(int a, int b);

    public static void main(String[] args) {
        App app = new App();
        int num1 = 40;
        int num2 = 2;
        
        // Invoke the native method
        int result = app.addNumbers(num1, num2);
        System.out.println("Result from C implementation: " + result);
    }
}


Step 2: Generate the JNI Header File

Compile the Java file and use the -h flag to generate the automatic C function signature wrapper:
bash
javac -h . App.java
Use code with caution.
This generates a file named App.h in your current directory. It contains the exact function name mapping that JNI expects:

c
/* DO NOT EDIT THIS FILE - it is machine generated */
#include <jni.h>
/* Header for class App */

#ifndef _Included_App
#define _Included_App
#ifdef __cplusplus
extern "C" {
#endif
/*
 * Class:     App
 * Method:    addNumbers
 * Signature: (II)I
 */
JNIEXPORT jint JNICALL Java_App_addNumbers
  (JNIEnv *, jobject, jint, jint);

#ifdef __cplusplus
}
#endif
#endif


Step 3: Write the Actual C Functionality (calculator.c and calculator.h)

This is your core C logic. Notice that it contains zero JNI or Java dependencies. It is standard, standalone C code.
calculator.h
c
#ifndef CALCULATOR_H
#define CALCULATOR_H

int core_add(int a, int b);

#endif

c
#include "calculator.h"

// Pure C implementation
int core_add(int a, int b) {
    return a + b;
}


Step 4: Write the C JNI Bridge Layer (AppJNI.c)

This program acts as the adapter. It includes the auto-generated App.h and translates JNI types to your core C logic parameters.
AppJNI.c
c
#include <jni.h>
#include "App.h"         // Generated JNI header
#include "calculator.h"  // Actual C program header

// Implement the function prototype defined in App.h
JNIEXPORT jint JNICALL Java_App_addNumbers(JNIEnv *env, jobject obj, jint a, jint b) {
    
    // Map jint (Java ints) directly to standard C integers and call the core C logic
    int result = core_add((int)a, (int)b);
    
    // Return the result back as a jint
    return (jint)result;
}



Step 5: Compile into a Shared Library

You need to compile both calculator.c and AppJNI.c together into a single dynamic library. You must provide GCC with paths to your JDK's jni.h folder.
Find your $JAVA_HOME path and run the command matching your operating system:

gcc -shared -o mycalculator.dll AppJNI.c calculator.c -I"%JAVA_HOME%\include" -I"%JAVA_HOME%\include\win32"



java -Djava.library.path=. App
